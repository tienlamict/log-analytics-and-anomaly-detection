       - Define `SMTPConfig` struct (mirrors config.SMTPConfig but lives in this package for constructor use):
         ```go
         type SMTPConfig struct {
             Host       string
             Port       int
             Username   string
             Password   string
             From       string
             Recipients []string
             TLSPolicy  string // "mandatory", "opportunistic", "none"
         }
         ```

       - Struct `SMTPAlerter`:
         ```go
         type SMTPAlerter struct {
             client *mail.Client
             cfg    SMTPConfig
             logger *zap.Logger
             queue  chan domain.Anomaly
         }
         ```

       - Constructor `NewSMTPAlerter(cfg SMTPConfig, logger *zap.Logger) (*SMTPAlerter, error)`:
         - Parse TLS policy: `parseTLSPolicy(cfg.TLSPolicy)` -> `mail.TLSPolicy`
         - Create go-mail client:
           ```go
           client, err := mail.NewClient(cfg.Host,
               mail.WithPort(cfg.Port),
               mail.WithSMTPAuth(mail.SMTPAuthPlain),
               mail.WithUsername(cfg.Username),
               mail.WithPassword(cfg.Password),
               mail.WithTLSPolicy(tlsPolicy),
               mail.WithTimeout(30*time.Second),
           )
           ```
         - Note: Use `mail.WithPort(cfg.Port)` + `mail.WithTLSPolicy(tlsPolicy)` since port is explicit from config (not WithTLSPortPolicy which auto-selects port). Per Pitfall 6, when port is explicitly set, use WithTLSPolicy.
         - If `cfg.Username == ""`, skip `mail.WithSMTPAuth` and `mail.WithUsername`/`mail.WithPassword` (local dev MailHog needs no auth). Build options slice conditionally.
         - Create buffered queue: `make(chan domain.Anomaly, 100)`
         - Return `&SMTPAlerter{client, cfg, logger, queue}, nil`

       - Helper `parseTLSPolicy(s string) (mail.TLSPolicy, error)`:
         - `"mandatory"` -> `mail.TLSMandatory`
         - `"opportunistic"` -> `mail.TLSOpportunistic`
         - `"none"` or `""` -> `mail.NoTLS`
         - default -> `return 0, fmt.Errorf("unknown TLS policy: %q", s)`

       - Method `Name() string` -> returns `"smtp"`

       - Method `Send(_ context.Context, anomaly domain.Anomaly) error`:
         - Non-blocking enqueue to `a.queue`:
           ```go
           select {
           case a.queue <- anomaly:
               return nil
           default:
               a.logger.Warn("smtp alert queue full, dropping anomaly", zap.String("rule_id", anomaly.RuleID))
               metrics.EmailAlertsFailedTotal.Inc()
               return nil  // non-fatal
           }
           ```

       - Method `Run(ctx context.Context)`:
         - Loop reading from `a.queue` with ctx.Done select
         - On anomaly: call `a.dispatch(ctx, anomaly)`
         - On ctx.Done: drain remaining items from queue then return

       - Method `dispatch(ctx context.Context, anomaly domain.Anomaly)`:
         - Build message via `mail.NewMsg()`
         - `m.From(a.cfg.From)`, `m.To(a.cfg.Recipients...)`
         - Subject: `fmt.Sprintf("[%s] %s - %s", strings.ToUpper(anomaly.Severity), anomaly.RuleID, anomaly.Service)`
         - Body: `m.SetBodyString(mail.TypeTextPlain, formatAlertBody(anomaly))`
         - Call `a.client.DialAndSendWithContext(ctx, m)`
         - On error: log with zap, increment `metrics.EmailAlertsFailedTotal`, return (do not propagate)
         - On success: increment `metrics.EmailAlertsSentTotal`

       - Function `formatAlertBody(a domain.Anomaly) string`:
         - Uses strings.Builder to format:
           ```
           Anomaly Detected

           Type:         {a.RuleID}
           Service:      {a.Service}
           Severity:     {a.Severity}
           Detected At:  {a.DetectedAt.UTC().Format(time.RFC3339)}
           Description:  {a.Description}

           Sample Log Lines:
             [{entry.Timestamp.UTC().Format(time.RFC3339)}] {entry.Level}: {entry.Message}
             ...
           ```
         - Cap sample log lines at 5 entries (`if i >= 5 { break }`)
