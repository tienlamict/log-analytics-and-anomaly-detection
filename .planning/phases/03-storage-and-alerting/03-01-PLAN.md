    2. Create `internal/elasticsearch/client.go`:
       - Package `elasticsearch`
       - Import `elasticsearch "github.com/elastic/go-elasticsearch/v9"` and `"net/http"`
       - Define `ESConfig` struct (used locally, mirrored by config package):
         ```
         type ClientConfig struct {
             Addresses       []string
             Username        string
             Password        string
             MaxIdleConns    int
             ResponseTimeout time.Duration
         }
         ```
       - Function `NewClient(cfg ClientConfig) (*elasticsearch.TypedClient, error)`:
         - Creates `elasticsearch.NewTypedClient(elasticsearch.Config{...})` with:
           - `Addresses: cfg.Addresses`
           - `Username: cfg.Username`
           - `Password: cfg.Password`
           - Custom `Transport: &http.Transport{MaxIdleConnsPerHost: cfg.MaxIdleConns, ResponseHeaderTimeout: cfg.ResponseTimeout}`
           - `RetryOnStatus: []int{502, 503, 504, 429}`
           - `MaxRetries: 3`
         - Default `MaxIdleConns` to 10 if zero, `ResponseTimeout` to 10s if zero

    3. Create `internal/elasticsearch/setup.go`:
       - Function `ApplyIndexTemplates(ctx context.Context, client *elasticsearch.TypedClient) error`:
         - Calls `applyLogsTemplate(ctx, client)` then `applyAnomaliesTemplate(ctx, client)`
         - Returns first non-nil error (fail-fast)
       - Function `applyLogsTemplate(ctx, client)`:
         - Uses `putindextemplate.Request` with `IndexPatterns: []string{"logs-*"}`, `Priority: 100`
         - Mapping properties (all with `dynamic: false` via `dynamicmapping.False`):
           - `@timestamp` -> `types.DateProperty{}`
           - `level` -> `types.KeywordProperty{}`
           - `service` -> `types.KeywordProperty{}`
           - `message` -> `types.TextProperty{}`
           - `fields` -> `types.FlattenedProperty{}` (prevents mapping explosion)
           - `raw_source` -> `types.KeywordProperty{}`
         - Calls `client.Indices().PutIndexTemplate("logs-template").Request(req).Do(ctx)`
       - Function `applyAnomaliesTemplate(ctx, client)`:
         - `IndexPatterns: []string{"anomalies"}`, `Priority: 100`
         - Mapping properties (dynamic: false):
           - `id` -> `types.KeywordProperty{}`
           - `rule_id` -> `types.KeywordProperty{}`
           - `severity` -> `types.KeywordProperty{}`
           - `service` -> `types.KeywordProperty{}`
           - `description` -> `types.TextProperty{}`
           - `detected_at` -> `types.DateProperty{}`
           - `evidence` -> `types.FlattenedProperty{}`
         - Calls `client.Indices().PutIndexTemplate("anomalies-template").Request(req).Do(ctx)`

    4. Create `internal/elasticsearch/setup_test.go`:
       - Use mock transport pattern from research (mockTransport with RoundTripFunc)
       - `TestApplyIndexTemplates_Success`: mock returns 200 with `{"acknowledged":true}` for both PUT requests; verify no error; verify both template names ("logs-template", "anomalies-template") appear in request URLs
       - `TestApplyIndexTemplates_LogsTemplateFailure`: mock returns error for first request; verify `ApplyIndexTemplates` returns error containing "logs"
       - `TestApplyIndexTemplates_AnomaliesTemplateFailure`: mock returns 200 for logs but error for anomalies; verify error returned
       - All tests use `elasticsearch.NewClient` (not TypedClient) with mock transport since the TypedClient wraps the base client. Use `elasticsearch.NewClient(elasticsearch.Config{Transport: &mockTransport{...}})` then get the typed client or use `elasticsearch.NewTypedClient(elasticsearch.Config{Transport: &mockTransport{...}})`.
       - IMPORTANT: The mock transport must include `Header: http.Header{"X-Elastic-Product": []string{"Elasticsearch"}}` in responses — the v9 client validates this header.
