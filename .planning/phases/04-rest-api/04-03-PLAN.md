   - `func parseTimeParam(r *http.Request, name string) (time.Time, error)` — get query param, parse RFC3339, return zero time if empty

2. Create `internal/api/anomalies.go`:
   - Package `api`
   - Imports: `"errors"`, `"net/http"`, `"github.com/go-chi/chi/v5"`, `"go.uber.org/zap"`, `"github.com/log-analytics/server/internal/domain"`

   - Define `func (s *Server) handleListAnomalies(w http.ResponseWriter, r *http.Request)`:
     - Parse query params:
       - `ruleType := r.URL.Query().Get("type")` — this is the anomaly type/rule filter
       - `service := r.URL.Query().Get("service")`
       - `severity := r.URL.Query().Get("severity")`
       - `page, err := parseIntParam(r, "page", 1, 1, 10000)` — on error: `writeError(w, 400, err.Error()); return`
       - `size, err := parseIntParam(r, "size", 20, 1, 1000)` — on error: `writeError(w, 400, err.Error()); return`
       - `from, err := parseTimeParam(r, "from")` — on error: `writeError(w, 400, err.Error()); return`
       - `to, err := parseTimeParam(r, "to")` — on error: `writeError(w, 400, err.Error()); return`
     - Build `domain.AnomalyQuery{Type: ruleType, Service: service, Severity: severity, From: from, To: to, Page: page, Size: size}`
     - Call `anomalies, total, err := s.anomStore.SearchAnomalies(r.Context(), q)`
     - If err != nil: `s.logger.Error("search anomalies failed", zap.Error(err)); writeError(w, 500, "internal error"); return`
     - `writeJSON(w, 200, PagedResponse{Data: anomalies, Total: total, Page: page, Size: size})`

   - Define `func (s *Server) handleGetAnomaly(w http.ResponseWriter, r *http.Request)`:
     - `id := chi.URLParam(r, "id")`
     - If `id == ""`: `writeError(w, 400, "missing id"); return`
     - `anomaly, err := s.anomStore.GetAnomaly(r.Context(), id)`
     - If err != nil and `errors.Is(err, domain.ErrNotFound)`: `writeError(w, 404, "anomaly not found"); return`
     - If err != nil (other): `s.logger.Error("get anomaly failed", zap.Error(err), zap.String("id", id)); writeError(w, 500, "internal error"); return`
     - `writeJSON(w, 200, anomaly)`

3. Update `internal/api/server.go` — inside the `r.Route("/api/v1", ...)` block, register:
   - `r.Get("/anomalies", s.handleListAnomalies)`
   - `r.Get("/anomalies/{id}", s.handleGetAnomaly)`

   NOTE: If 04-02 has already run and added log routes, just add the anomaly routes alongside. If 04-02 has not run yet, add both anomaly routes and leave comments for log routes. Check the current state of server.go before editing.
