Implement `NormaliseLevel(raw string) string`:
```go
func NormaliseLevel(raw string) string {
    switch strings.ToUpper(strings.TrimSpace(raw)) {
    case "ERROR", "ERR", "FATAL", "CRITICAL", "CRIT":
        return "error"
    case "WARN", "WARNING":
        return "warn"
    case "INFO", "INFORMATION":
        return "info"
    case "DEBUG", "TRACE", "VERBOSE":
        return "debug"
    default:
        return "unknown"
    }
}
```

Implement `Parse(msg domain.RawMessage) (domain.LogEntry, error)`:

1. Attempt JSON unmarshal of `msg.Payload` into a temporary struct:
```go
var structured struct {
    Timestamp string         `json:"timestamp"`
    Level     string         `json:"level"`
    Service   string         `json:"service"`
    Message   string         `json:"message"`
    Fields    map[string]any `json:"fields"`
}
```

2. If JSON unmarshal succeeds:
   - Parse Timestamp with `time.Parse(time.RFC3339, structured.Timestamp)`. If parse fails, use `time.Now()`.
   - Create LogEntry with:
     - ID: `uuid.NewString()`
     - Timestamp: parsed timestamp
     - Level: `NormaliseLevel(structured.Level)`
     - Service: `structured.Service`
     - Message: `structured.Message`
     - Fields: `structured.Fields`
     - RawSource: `string(msg.Payload)`
     - Source: `msg` (the full RawMessage, for offset tracking)
   - Return entry with `nil` error.

3. If JSON unmarshal fails (plain-text fallback):
   - Create LogEntry with:
     - ID: `uuid.NewString()`
     - Timestamp: `time.Now()`
     - Level: `"unknown"`
     - Service: `""` (empty)
     - Message: `string(msg.Payload)`
     - Fields: `nil`
     - RawSource: `string(msg.Payload)`
     - Source: `msg`
   - Return entry with `fmt.Errorf("not valid JSON, stored as plain-text: %w", jsonErr)`.

CRITICAL: Parse ALWAYS returns a valid LogEntry. Even on error, the returned LogEntry is usable. The caller decides whether to log/meter the error — the parser never drops messages.

```go
type LogParser struct{}

func NewParser() *LogParser {

func (p *LogParser) Parse(msg domain.RawMessage) (domain.LogEntry, error) {

}
```
