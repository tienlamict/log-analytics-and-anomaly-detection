Constructor `New(cfg config.KafkaConfig, logger *zap.Logger) (*Consumer, error)`:
1. Resolve initial offset: if `cfg.InitialOffset == "newest"` use `kgo.NewOffset().AtEnd()`, otherwise default to `kgo.NewOffset().AtStart()`.
2. Create kgo.Client with these options:
   - `kgo.SeedBrokers(cfg.Brokers...)`
   - `kgo.ConsumerGroup(cfg.GroupID)`
   - `kgo.ConsumeTopics(cfg.Topic)`
   - `kgo.ConsumeResetOffset(initialOffset)`
   - `kgo.AutoCommitMarks()` — CRITICAL: only commits records explicitly passed to MarkCommitRecords
   - `kgo.OnPartitionsRevoked(onRevoked)` — see below
   - `kgo.WithLogger(kzap.New(logger))`
3. Create buffered output channel with capacity 1000.
4. Return &Consumer{client, out, logger}, nil.

The `onRevoked` callback (closure or method):
```go
onRevoked := func(ctx context.Context, cl *kgo.Client, _ map[string][]int32) {
    if err := cl.CommitMarkedOffsets(ctx); err != nil {
        logger.Error("commit on revoke failed", zap.Error(err))
    }
}
```

Method `Run(ctx context.Context) error`:
```go
func (c *Consumer) Run(ctx context.Context) error {
    defer close(c.out)
    defer c.client.Close()
    for {
        fetches := c.client.PollFetches(ctx)
        if fetches.IsClientClosed() {
            return nil
        }
        if ctx.Err() != nil {
            return ctx.Err()
        }
        fetches.EachError(func(t string, p int32, err error) {
            c.logger.Error("fetch error",
                zap.String("topic", t),
                zap.Int32("partition", p),
                zap.Error(err),
            )
        })
        fetches.EachRecord(func(r *kgo.Record) {
            msg := domain.RawMessage{
                Payload:   r.Value,
                Topic:     r.Topic,
                Partition: r.Partition,
                Offset:    r.Offset,
                Timestamp: r.Timestamp,
            }
            select {
            case c.out <- msg:
                c.client.MarkCommitRecords(r) // CRITICAL: Mark AFTER channel send succeeds
            case <-ctx.Done():
                return
            }
        })
    }
}
```

CRITICAL ordering: `c.out <- msg` MUST succeed before `c.client.MarkCommitRecords(r)`. Reversing this order causes silent data loss on crash (Pitfall K1 from research).

Method `Messages() <-chan domain.RawMessage`:
```go
func (c *Consumer) Messages() <-chan domain.RawMessage {
    return c.out
}
```
