Define a `mockDetector` for engine tests:
```go
type mockDetector struct {
    name     string
    fireNext bool
    anomaly  domain.Anomaly
    evaluated int
    resetCount int
}

func (m *mockDetector) Name() string { return m.name }
func (m *mockDetector) Evaluate(entry domain.LogEntry) (domain.Anomaly, bool) {
    m.evaluated++
    if m.fireNext {
        return m.anomaly, true
    }
    return domain.Anomaly{}, false
}
func (m *mockDetector) Reset() { m.resetCount++ }
```

For reading anomalies from the channel, use a helper:
```go
func drainAnomalies(ch <-chan domain.Anomaly, timeout time.Duration) []domain.Anomaly {
    var results []domain.Anomaly
    timer := time.NewTimer(timeout)
    defer timer.Stop()
    for {
        select {
        case a := <-ch:
            results = append(results, a)
        case <-timer.C:
            return results
        }
    }
}
```

Use short durations throughout (100ms-500ms) to keep test runtime under 5 seconds total. All engine tests call `engine.Stop()` in a `defer` or `t.Cleanup` to prevent goroutine leaks.
