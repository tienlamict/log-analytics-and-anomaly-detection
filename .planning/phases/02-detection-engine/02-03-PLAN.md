**AuthFailureBurstRule** (`internal/detection/auth_burst.go`):

Package `detection`. Imports: domain, fmt, time, github.com/google/uuid.

1. Struct `AuthFailureBurstRule`:
   - `windows map[string]*slidingWindow` -- keyed by extracted IP or username
   - `cfg AuthBurstConfig`
   - `capacity int` -- 10000

2. Constructor: `NewAuthFailureBurstRule(cfg AuthBurstConfig) *AuthFailureBurstRule`
   - If cfg.IPField is empty, default to `"source_ip"`
   - If cfg.UserField is empty, default to `"username"`

3. `Name()` returns `"auth_failure_burst"`

4. `Evaluate(entry domain.LogEntry) (domain.Anomaly, bool)`:
   - First, determine if this is an auth failure event. Check: `entry.Level == "error"` AND (entry.Message contains "auth" or "login" or "unauthorized" case-insensitively, OR entry.Fields has a key "auth_result" with value "failure")
   - Extract key: try `entry.Fields[r.cfg.IPField]` as string first. If not present, try `entry.Fields[r.cfg.UserField]`. If neither present, return false (cannot key this event).
   - Get or create slidingWindow for key
   - `w.Add(entry.Timestamp)`
   - count = `w.CountWithin(r.cfg.Window)`
   - If count >= r.cfg.Threshold: return Anomaly with RuleID="auth_failure_burst", Severity=r.cfg.Severity, Service=entry.Service, Description=fmt.Sprintf("auth failure burst: %d failures from %s in %s", count, key, r.cfg.Window), Evidence=[]domain.LogEntry{entry}

5. `Reset()`: evict stale entries per key, delete zero-count keys.

**OffHoursAccessRule** (`internal/detection/off_hours.go`):

Package `detection`. Imports: domain, fmt, time, github.com/google/uuid, strings.

1. Struct `OffHoursAccessRule`:
   - `cfg OffHoursConfig`
   - `loc *time.Location` -- loaded from cfg.Timezone

2. Constructor: `NewOffHoursAccessRule(cfg OffHoursConfig) (*OffHoursAccessRule, error)`:
   - If cfg.Timezone == "" or cfg.Timezone == "UTC", use time.UTC
   - Otherwise, `loc, err := time.LoadLocation(cfg.Timezone)`; return error if invalid
   - Return rule with loc set

3. `Name()` returns `"off_hours_access"`

4. Helper: `isSensitivePath(path string) bool` -- check if path starts with any entry in cfg.SensitivePaths (use `strings.HasPrefix` for prefix matching)

5. `Evaluate(entry domain.LogEntry) (domain.Anomaly, bool)`:
   - Extract path: `path, ok := entry.Fields["path"].(string)` -- if not present, return false
   - If `!r.isSensitivePath(path)` return false
   - Convert entry timestamp to configured timezone: `hour := entry.Timestamp.In(r.loc).Hour()`
   - If `hour >= r.cfg.BusinessHoursStart && hour < r.cfg.BusinessHoursEnd` return false (within business hours)
   - Return Anomaly with Description=fmt.Sprintf("off-hours access to %s at %02d:00 by service %s", path, hour, entry.Service)
   - NOTE: This rule is STATELESS -- no window needed. Every off-hours access to a sensitive path fires immediately.

6. `Reset()`: no-op (stateless rule)

Create `internal/detection/service_silence.go` in package `detection`:

This rule is SPECIAL: it fires on ABSENCE of events, not presence. It uses the adapter pattern:
- `Evaluate(entry)` only updates lastSeen state, always returns false
- `CheckSilence()` is called by the engine's heartbeat goroutine to detect silent services

1. Struct `ServiceSilenceRule`:
   - `lastSeen map[string]time.Time` -- service -> last log timestamp
   - `seenCount map[string]int` -- service -> count of logs seen (cold-start guard)
   - `cfg ServiceSilenceConfig`
   - `mu sync.Mutex` -- needed because Evaluate is called from pipeline goroutine, CheckSilence from heartbeat goroutine

2. Constructor: `NewServiceSilenceRule(cfg ServiceSilenceConfig) *ServiceSilenceRule`
   - Initialize both maps

3. `Name()` returns `"service_silence"`

4. `Evaluate(entry domain.LogEntry) (domain.Anomaly, bool)`:
   - `r.mu.Lock(); defer r.mu.Unlock()`
   - Increment `r.seenCount[entry.Service]`
   - If `r.seenCount[entry.Service] >= r.cfg.MinLogCount`: update `r.lastSeen[entry.Service] = time.Now()`
   - Always return `domain.Anomaly{}, false` -- this rule never fires from Evaluate
   - NOTE: Use `time.Now()` here (not entry.Timestamp) because we're tracking INGEST time for silence detection

5. `CheckSilence() []domain.Anomaly`:
   - `r.mu.Lock(); defer r.mu.Unlock()`
   - Iterate `r.lastSeen`
   - For each service where `time.Since(lastTime) > r.cfg.SilenceAfter`:
     - Create Anomaly with RuleID="service_silence", Severity=r.cfg.Severity, Service=service, Description=fmt.Sprintf("service silence: %s has not emitted logs for %s (threshold: %s)", service, time.Since(lastTime).Round(time.Second), r.cfg.SilenceAfter)
     - Remove from lastSeen (will re-enter tracking once new logs arrive and hit MinLogCount again)
     - Append to results
   - Return anomaly slice

6. `Reset()`:
   - `r.mu.Lock(); defer r.mu.Unlock()`
   - Remove entries from seenCount and lastSeen for services not seen recently (where `time.Since(lastSeen) > r.cfg.SilenceAfter * 3`). This is the eviction path for unbounded memory growth prevention.
   - Do NOT clear all state.

IMPORTANT: This is the ONLY rule that needs a sync.Mutex because it crosses goroutine boundaries (Evaluate from pipeline goroutine, CheckSilence from heartbeat goroutine). All other rules are single-goroutine safe by design (Pitfall G2).

Also add a method to the engine to integrate the silence heartbeat. This requires modifying engine.go -- add:
- A `silenceRule *ServiceSilenceRule` field on DetectorEngine (nil if no silence rule registered)
- In `NewDetectorEngine`, type-assert each detector: if it's a `*ServiceSilenceRule`, store the reference and start a heartbeat goroutine
- `silenceWatcher(sr *ServiceSilenceRule)` goroutine: uses `time.NewTicker(sr.cfg.CheckInterval)`, calls `sr.CheckSilence()`, applies cooldown check, sends anomalies to `e.out`
- The heartbeat goroutine also stops on `e.evictStop`
