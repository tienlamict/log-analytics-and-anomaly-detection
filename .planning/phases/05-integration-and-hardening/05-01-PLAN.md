2. **Kafka consumer**:
   - Call `kafka.New(cfg.Kafka, logger)`

3. **Detection engine** — build all 7 rules from config:
   - `detection.NewErrorRateRule(cfg.Detection.Rules.ErrorRate)`
   - `detection.NewLatencyThresholdRule(cfg.Detection.Rules.Latency)`
   - `detection.NewRepeatedFailureRule(cfg.Detection.Rules.RepeatedFailure)`
   - `detection.NewOffHoursAccessRule(cfg.Detection.Rules.OffHours)` (returns error)
   - `detection.NewAuthFailureBurstRule(cfg.Detection.Rules.AuthBurst)`
   - `detection.NewServiceSilenceRule(cfg.Detection.Rules.ServiceSilence)`
   - Collect into `[]domain.Detector` slice, call `detection.NewDetectorEngine(detectors, cfg.Detection, logger)`

4. **SMTP alerter**:
   - Convert `cfg.SMTP` (config.SMTPConfig) to `smtp.SMTPConfig{Host: cfg.SMTP.Host, Port: cfg.SMTP.Port, Username: cfg.SMTP.Username, Password: cfg.SMTP.Password, From: cfg.SMTP.From, Recipients: cfg.SMTP.Recipients, TLSPolicy: cfg.SMTP.TLSPolicy}`
   - Call `smtp.NewSMTPAlerter(smtpCfg, logger)`

5. **Alert dispatcher**:
   - `alert.NewDispatcher(engine.Anomalies(), anomalyIndexer, alerter, logger)`

6. **API server**:
   - `api.NewServer(logIndexer, anomalyIndexer, esClient, logger, cfg.API.Port)`

7. **errgroup goroutines** (per Pattern 6 from RESEARCH.md):
   - `g.Go(func() error { return consumer.Run(gCtx) })` — Kafka consumer
   - `g.Go(func() error { ... range consumer.Messages() ... pipeline.Parse(msg) ... logIndexer.IndexLog(gCtx, entry) ... engine.Evaluate(entry) ... })` — pipeline worker that parses each message, indexes the log, and evaluates for anomalies. Log parse errors with `logger.Warn` but continue processing (parser always returns an entry).
   - `g.Go(func() error { return dispatcher.Run(gCtx) })` — anomaly dispatcher
   - `g.Go(func() error { alerter.Run(gCtx); return nil })` — SMTP alerter
   - `g.Go(func() error { ... apiServer.ListenAndServe() ... })` — API server (ignore http.ErrServerClosed)
   - `g.Go(func() error { <-gCtx.Done(); ... shutdown watcher ... })` — LIFO shutdown watcher:
     a. Create `shutdownCtx, cancel := context.WithTimeout(context.Background(), 8*time.Second)`
     b. `apiServer.Shutdown(shutdownCtx)`
     c. `engine.Stop()`
     d. `logIndexer.Close(shutdownCtx)`
     e. `anomalyIndexer.Close(shutdownCtx)`
     f. `cancel()` and `return nil`

8. Call `apiServer.SetReady()` after all setup completes (before `g.Wait()`)

9. Return `g.Wait()` filtering out `context.Canceled` (return nil if the only error is context.Canceled)

**Step 2: Create `internal/integration/main_test.go`:**

```go
//go:build integration

package integration

import (
    "context"
    "log"
    "testing"

    elasticsearch "github.com/elastic/go-elasticsearch/v9"
    "github.com/testcontainers/testcontainers-go"
    tces "github.com/testcontainers/testcontainers-go/modules/elasticsearch"
    tckafka "github.com/testcontainers/testcontainers-go/modules/kafka"
    "go.uber.org/goleak"
)

var (
    kafkaContainer *tckafka.KafkaContainer
    esContainer    *tces.ElasticsearchContainer
    kafkaBrokers   []string
    esAddress      string
    esCACert       []byte
)

func TestMain(m *testing.M) {
    ctx := context.Background()

    var err error
    kafkaContainer, err = tckafka.Run(ctx,
        "confluentinc/confluent-local:7.5.0",
        tckafka.WithClusterID("test-cluster"),
    )
    if err != nil {
        log.Fatalf("failed to start kafka container: %s", err)
    }
    defer func() {
        if err := testcontainers.TerminateContainer(kafkaContainer); err != nil {
            log.Printf("terminate kafka: %s", err)
        }
    }()

    kafkaBrokers, err = kafkaContainer.Brokers(ctx)
    if err != nil {
        log.Fatalf("failed to get kafka brokers: %s", err)
    }

    esContainer, err = tces.Run(ctx,
        "docker.elastic.co/elasticsearch/elasticsearch:8.9.0",
        tces.WithPassword("changeme"),
    )
    if err != nil {
        log.Fatalf("failed to start elasticsearch container: %s", err)
    }
    defer func() {
        if err := testcontainers.TerminateContainer(esContainer); err != nil {
            log.Printf("terminate es: %s", err)
        }
    }()

    esAddress = esContainer.Settings.Address
    esCACert = esContainer.Settings.CACert

    goleak.VerifyTestMain(m,
        goleak.IgnoreTopFunction("net/http.(*persistConn).writeLoop"),
        goleak.IgnoreTopFunction("internal/poll.runtime_pollWait"),
    )
}

// newESClient builds a TypedClient from the container settings.
// This bypasses the project's NewClient to use CACert for TLS.
func newESClient() (*elasticsearch.TypedClient, error) {
    return elasticsearch.NewTypedClient(elasticsearch.Config{
        Addresses: []string{esAddress},
        Username:  "elastic",
        Password:  "changeme",
        CACert:    esCACert,
    })
}
```

**CRITICAL:** `goleak.VerifyTestMain(m)` calls `m.Run()` internally. Do NOT also call `os.Exit(m.Run())`. Add `goleak.IgnoreTopFunction` filters for known testcontainers/HTTP goroutines to avoid false positives.
